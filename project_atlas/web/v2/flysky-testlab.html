    What the link states mean

    • Connected Valid frames are arriving now.
    • Signal not verified No decoded frame. A paired receiver with a lit LED is not enough.
    • Stale / lost Frames stopped for more than 0.5 s / 3 s.
    • Failsafe / dropped The receiver says so in its flags (SBUS only).

    Second remote driving disabled

    Design only. The existing controller stays the only remote that can drive. When FlySky driving is approved later: one active remote at a time, chosen explicitly, E-STOP always wins, signal loss stops the rover, and stale commands are never forwarded.
