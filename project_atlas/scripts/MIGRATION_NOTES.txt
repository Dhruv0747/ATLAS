JETSON SETUP STEPS
  1. Flash JetPack 6.x (Ubuntu 22.04)
  2. Install ROS2 Humble (NOT Jazzy - not supported on Jetson)
  3. pip3 install vl53l0x ina260 ssd1306 smbus2
  4. GPIO: replace RPi.GPIO imports with Jetson.GPIO
  5. I2C: check bus numbers with i2cdetect -l
  6. Camera: use GStreamer pipeline - nvarguscamerasrc for CSI camera
  7. Serial: /dev/ttyUSB0 Yahboom, check radar ttyAMA path
  8. YOLO: yolo export model=yolov8n.pt format=engine device=0
